# Examples

Runnable examples. They are not installed or tested with the package.

| Folder | What |
|---|---|
| [`tutorials/`](tutorials/) | Notebooks on a local database, starting with [Getting started](tutorials/01_getting_started.ipynb). Also shown in the documentation. Run them from that folder. |
| [`mlai_mouse_ar/`](mlai_mouse_ar/) | A real lab pipeline (Mathis lab, Mouse AR) on the shared tables, including its legacy tables. Start at [`mouse_ar_example.py`](mlai_mouse_ar/mouse_ar_example.py). |

A local database: `make init` once, then `make db_up` (from the repository root).
